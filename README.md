### 👋 About Me

Yo! Main **YashXChi** (aka **roardiamond**) hoon — full-stack developer jo gaming tools, automation hubs aur premium experiences banata hai.  

Currently **VOIDXHUB** pe kaam kar raha hoon — ek underground-style automation & tools platform Free Fire, BGMI players ke liye. Secure backends, credits system, Razorpay integration, tournaments — sab kuch production level pe.  

Passionate about clean code, fast UIs, and tools that actually help gamers dominate.
