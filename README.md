### About Me

```diff
+ Name          : YashXChi (roardiamond)
+ Role          : Full-Stack Developer | Platform Architect
+ Focus         : VOIDXHUB Ecosystem & Scalable Web Applications
+ Approach      : Clean architecture, production-grade systems, dark-mode first design
```

I am a full-stack developer specializing in building high-performance web applications, backend systems, and mobile solutions.  
My primary focus is the **VOIDXHUB** ecosystem — a comprehensive platform providing advanced tools, tournament management, and utility services for the gaming community.

I emphasize clean code, secure authentication flows, payment integrations, and maintainable architecture across the entire stack.

**Current Priorities:**
- Developing and refining the complete VOIDXHUB stack (Web + Backend + Mobile)
- Building robust authentication, credits, and payment systems
- Creating polished, production-ready interfaces and admin panels

**Core Technologies:** TypeScript • Next.js • React • Python • Node.js • Capacitor

Open to collaborations on SaaS platforms, automation tools, and gaming-related software products.
